Task 7 – Spring Boot Application with 4 Endpoints and Layered Architecture

In this task, I created a Spring Boot application with at least four RESTful endpoints following a layered architecture — Controller, Service, and Repository.
The implementation includes:

1. Input validation using annotations like @Valid and @NotNull.
2. Exception handling with a global error handler to manage runtime and validation errors.
3. Service injection using @Autowired for clean separation of business logic.
4. Secured resource endpoint to restrict unauthorized access.
5. REST API specification demonstrating endpoint documentation and usage.
