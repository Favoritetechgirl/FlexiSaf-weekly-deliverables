Task 6 – Practicing Dependency Injection in Spring Boot

In this task, I practiced dependency injection in Spring Boot using constructor, setter, and field injection.
The goal was to understand how Spring manages bean creation and wiring using the @Autowired annotation.
Each injection type was implemented following best practices for business logic implementation to ensure cleaner, maintainable, and testable code.
